# CivicSense

A civic grievance platform that allows citizens to submit and view complaints using Firebase Firestore.

## Features

- Submit complaints
- Store complaints in Firebase
- View all complaints
- Cloud database integration

## Tech Stack

- HTML
- CSS
- JavaScript
- Firebase Firestore
